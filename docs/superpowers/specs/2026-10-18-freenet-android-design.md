# FreeNet для Android на Java — спецификация

Дата: 18 октября 2026 года

## Цель

Перенести учебный проект FreeNet из набора HTML/CSS/JavaScript-файлов в простое Android-приложение на Java. Приложение должно показывать те же 210 записей координат Wi-Fi-точек в Уфе, определять местоположение, находить ближайшую точку, показывать маршрут и копировать координаты. Карта области с точками должна загружаться при первом запуске и оставаться доступной без подключения к интернету.

Код предназначен для изучения: файлы и методы имеют одну понятную задачу, логика написана без лишних абстракций, а по-русски написанные комментарии объясняют назначение важных команд. README объясняет устройство приложения и запуск в Android Studio.

## Что делает исходный проект

- На стартовой странице описывает возможности FreeNet и инструкции установки PWA.
- На карте Leaflet показывает 210 записей координат в Уфе, включая повторяющиеся координаты.
- Определяет геопозицию пользователя, ищет ближайшую точку по формуле гаверсинусов, открывает маршрут в Яндекс Картах и копирует координаты.
- Сохраняет точки и состояние камеры в localStorage.
- Подложка Leaflet загружается с сервера OpenStreetMap, поэтому заявление об офлайн-работе в исходном проекте относится к данным точек, но не гарантирует офлайн-подложку.

## Архитектура приложения

Приложение остаётся небольшим нативным Android-проектом на Java. Интерфейс создаётся стандартными Android View и XML-разметкой. Карта отображается через MapLibre Native Android; работа с данными и действиями пользователя реализуется на Java, без WebView и Kotlin.

Основные части:

1. `MainActivity` создаёт экран карты и связывает элементы управления с обработчиками.
2. `WifiPoint` хранит номер и широту/долготу одной записи.
3. `WifiData` содержит перенесённые координаты и формирует границы офлайн-области.
4. `OfflineMapManager` создаёт, загружает и проверяет область карты через API MapLibre OfflineManager. Он показывает ход загрузки, сохраняет завершённую карту и позволяет повторить прерванную загрузку.
5. `LocationHelper` запрашивает разрешение Android и получает текущее местоположение.
6. `DistanceCalculator` содержит понятную реализацию формулы гаверсинусов и поиск ближайшей точки.
7. Простые настройки Android сохраняют позицию пользователя и завершённость загрузки.

Окно карты показывает FreeNet, число записей и три действия: определить местоположение, обновить экран/состояние карты, найти ближайшую точку. Выбор маркера открывает карточку с номером, координатами, расстоянием (если местоположение известно), кнопкой копирования и кнопкой маршрута. Открытие маршрута передаётся внешнему навигационному приложению через Android Intent; сам маршрут требует сети и установленного приложения-карты.

## Офлайн-карта при первом запуске

Используется стиль OpenFreeMap Liberty и механизм офлайн-регионов MapLibre. Приложение заранее знает границы данных и создаёт прямоугольную область, охватывающую все координаты точек с небольшим запасом. Для первоначальной загрузки используется диапазон zoom 10–15. По границам исходных координат и небольшому запасу расчётная область содержит около 2 245 базовых векторных тайлов. Точное число зависимых ресурсов и фактический размер проверяются callback-ами MapLibre во время загрузки.

Условия OpenFreeMap разрешают загрузку области не более 3 000 тайлов или 50 МБ за одну загрузку, не более четырёх параллельных запросов, с уникальным User-Agent приложения. Реализация ограничивает число параллельных запросов четырьмя и указывает идентификатор приложения в User-Agent. Перед выпуском необходимо подтвердить, что полный регион укладывается также в ограничение 50 МБ; если нет, уменьшить диапазон масштабов или область и описать это в интерфейсе/README. Атрибуция OpenStreetMap/OpenFreeMap остаётся видимой на карте.

При первом запуске приложение показывает экран/диалог загрузки с прогрессом. До её завершения пользователь видит понятное состояние и может повторить попытку. После завершения карта и стили доступны локально без интернета, а карта сразу открывается на Уфе. Данные точек встроены в приложение и поэтому доступны офлайн с первого старта. Обновление карты не должно происходить незаметно: основной сценарий — однократная первичная загрузка, позже можно вручную повторить загрузку при наличии сети.

OpenFreeMap предоставляет сервис «как есть» без гарантии доступности. Если сервис недоступен при первой установке, первичную карту завершить нельзя; приложение сохраняет понятную ошибку и кнопку повтора. Ранее загруженная область продолжает открываться без сети. Офлайн-доступ к карте ограничен прямоугольником Уфы и zoom 10–15; сетевое увеличение до более подробных уровней не считается частью гарантированного офлайн-сценария.

## Сценарии пользователя

1. При первом старте приложение объясняет, что оно загружает офлайн-карту, показывает прогресс и после успеха открывает Уфу с Wi-Fi-маркерами.
2. Если загрузка прервана или недоступна сеть, приложение показывает причину простыми словами и кнопку повтора.
3. При следующих стартах карта открывается из локального хранилища даже без сети.
4. Нажатие «Моё местоположение» запрашивает разрешение, показывает точку пользователя и центрирует карту; отказ не блокирует просмотр точек.
5. Нажатие «Ближайшая точка» вычисляет расстояния от текущей позиции, перемещает камеру к ближайшей точке и показывает её карточку. Если позиции пока нет, приложение просит определить её.
6. Нажатие «Копировать» помещает координаты в буфер обмена и показывает подтверждение.
7. Нажатие «Маршрут» передаёт целевые координаты внешнему навигационному приложению. Офлайн-маршрут приложением не рассчитывается.
8. Пользователь может обновить вид карты и повторно запросить загрузку области, когда доступен интернет.

## Разрешения и данные

Нужны разрешения `INTERNET`, `ACCESS_COARSE_LOCATION` и `ACCESS_FINE_LOCATION`; геопозиция запрашивается только после нажатия пользователем соответствующей кнопки. Координаты точек — учебные данные из `map.js`; приложение не отправляет геопозицию пользователя в собственный сервер. Геопозиция хранится только локально, если это понадобится для восстановления состояния.

## Обработка ошибок

- Нет интернет-соединения при первой загрузке: показать состояние без сети и кнопку повтора.
- Ошибка сервера или слишком большой регион: показать сообщение и не отмечать карту как загруженную.
- Мало места на устройстве или ошибка записи: показать, что загрузка не завершена; дать повторить после освобождения места.
- Пользователь отказал в геолокации или GPS выключен: сохранить доступ к карте, объяснить, как продолжить.
- Нет приложения для маршрута: показать сообщение, координаты всё ещё можно скопировать.
- Повреждённое сохранённое состояние камеры: открыть карту на центре Уфы.

## Проверка результата

Перед завершением реализации проверить сборку APK. На эмуляторе или устройстве проверить первичную загрузку с сетью, закрытие и повторный запуск без сети, отображение всех 210 записей, работу разрешения местоположения, поиск ближайшей точки, копирование и передачу маршрута. Отдельно проверить прерывание сети во время загрузки и повтор.

## Варианты картографической основы

- MapLibre + OpenFreeMap (выбран): нативная карта, API офлайн-областей, нет обязательного пользовательского API-ключа для публичного сервиса, условия явно допускают ограниченные офлайн-загрузки. Требуется соблюдать квоты, атрибуцию и уникальный User-Agent.
- MapLibre + стандартные тайлы OpenStreetMap: не подходит, потому что сервер `tile.openstreetmap.org` запрещает загрузку областей для офлайн-использования.
- Google Maps SDK: не выбран, потому что для простого учебного проекта требует ключ и не даёт подходящего разрешённого сценария автономного скачивания карты.
